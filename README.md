# Student Marks Calculator

## About the Project

A beginner-friendly Python project that calculates the total marks and average percentage for a student across three subjects.

## Features

* Accepts the student's name.
* Takes marks for three subjects.
* Calculates total marks.
* Calculates the average percentage.
* Displays the result.

## Technology Used

* Python

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `python student_marks.py`.
